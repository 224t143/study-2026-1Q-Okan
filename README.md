作品概要

本作品は、5月18日13時時点の気温、湿度、風速などの気候データを光の動きや明るさへ変換し、空間内に可視化する作品である。
環境情報を単なる数値として表示するのではなく、光の流れや光り方、速度として知覚的に体験できる表現を目指した。

TouchDesignerで環境データを入力・変換し、Arduino へシリアル通信を用いて送信している。
Arduinoでは受け取った数値をもとに、LEDテープの明るさ、流れる速度などを制御している。　

LED制御では0～255の数値を使用するため、各環境データをその範囲へ変換している。

各データは単位や範囲が異なるため、設定した範囲内でどれくらいの割合かを計算し、その割合を0〜255へ対応させている。

例えば気温30°Cの場合、0〜40°Cの範囲の中での割合を計算し、その割合を0〜255へ対応させてい
る。

30°Cは0～40°Cの中で75%にあたるため、0〜255の75%である約191へ変換している。

この191という数値を気温データとして使用している。
各範囲については今回の観測環境をもとに、現実的な変化範囲を想定して設定している。

気温
→brightness → 明るさ
湿度
→ blurAmount → ぼやけ感
風速
→ flowSpeed → 光の流れる速さ
UV指数
→ sharpness →光の鋭さ



制作意図

本作品では、展示会場などの空間内に存在するその場の雰囲気や空気感、環境の状態を可視化してみたいと考え制作を行った。
今回はその前段階として
気温、湿度、風速などの具体的な数値を入力し、それらを光の動きや明るさへ変換することで形にしてみた。

将来的にはAPIやWebカメラを用いてリアルタイムに情報を取得し、その場の空気感や人の動き、環境変化を作品へ反映させることで作品自体が変化し続けるインスタレーションへ発展させたいと考えている。
